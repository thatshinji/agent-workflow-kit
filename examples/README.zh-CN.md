# 示例

本目录是这套工作流的完整示例，每份都小到能一口气读完，又完整到可以直接照着抄。

| 示例 | 展示什么 |
|---|---|
| [invite-code/](invite-code/) | 一个功能（「用邀请码加入工作区」）完整走完八步流程：意图与契约 → 行为清单 → 验收门 → 带真实红绿证据的独立测试 → 带裁决的 review → 隐藏场景解封后的归档 |
| [delta-mode/](delta-mode/) | 同一个功能落到第二平台（移动端）：意图段只写平台差异，已有用例逐条映射（原样复用 / 适配 / 服务端专属），只新增三条平台用例——行为只决策一次，不按平台重复决策 |
| [hotfix/](hotfix/) | 一个生产 bug（过期码被报成不存在）走压缩通道：什么可以压缩（意图、验收门、用例清单），什么永远不行（回归用例先跑红、带裁决的评审、归档回写用例库） |

三个示例合起来覆盖这套工作流的三种节奏：功能的完整流程、第二平台的增量、紧急修复。
