# 第 8 步产物 — 合并后的归档状态

合并并不是流水线的终点。四项归档动作来收尾闭环：

## ① 隐藏场景解封进用例文件

Reviewer 提供了行为层底稿；Writer 把它们原样（只整格式）加进了 `docs/test-cases/workspace/invite-code.md`（即在 [02](02-behavior-cases.zh-CN.md) 中起草的那份文件的归档落点）：

- **INV-H1 格式错误的尝试也计数** — Given 一名用户在提交格式错误的邀请码（为空、形状不对），When 失败尝试达到限流阈值，Then 后续尝试——哪怕提交的是有效邀请码——也会被限流。
- **INV-H2 限流是按用户的** — Given 一名用户因失败尝试被限流，When 另一名用户提交有效邀请码，Then 加入成功。
